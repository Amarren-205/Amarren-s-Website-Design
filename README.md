# Amarren's Website Design

## Overview

Welcome to Amarren's Website Design! This repository contains my personal website, which demonstrates my knowledge and skills in web development.

The website introduces me, displays my projects, provides university resources, and allows visitors to interact with a contact form.

## Technologies Used

- **HTML5:** Provides the structure and content of the website.
- **CSS3:** Controls the website's appearance, layout, and styling.
- **JavaScript:** Adds interactive features, dynamic content, and user interaction.
- **JSON:** Converts project information into a format that can be stored and retrieved.
- **DOM Manipulation:** Dynamically creates and displays project information on the webpage.
- **Web Storage API:** Uses `localStorage` for dark mode preferences and `sessionStorage` for project information.

## Features

- About section introducing the website owner.
- Featured Content section with university resources and personal projects.
- Dynamically generated project cards.
- Contact form with a timed confirmation message.
- Welcome modal with a Close button.
- Submit button tooltip.
- Dark mode with saved preferences.
- Session storage for project information.

## Dependencies

This project uses standard HTML, CSS, and JavaScript. No external libraries or package installations are required.

The project uses:
- Browser support for HTML5 and CSS3.
- JavaScript support for DOM manipulation and events.
- Browser `localStorage` and `sessionStorage` APIs.
- An internet connection for externally hosted placeholder project images.

## Running the Website

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Explore the website and test its interactive features.

The website can also be viewed through GitHub Pages when publishing is enabled for the repository.
